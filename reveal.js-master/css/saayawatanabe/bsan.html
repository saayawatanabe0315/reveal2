目録法とSQLの定義

渡部紗朱

目録(・目録法)

目録とは、利用者が資料を「見つけ、見分け、選び、手に入れる」ために、資料のデータをそろえて検索できるようにまとめたものである。

データは、どんな資料か(書誌データ)、どこにあるか(所在データ)、名前などの表記をそろえるための典拠データの3種類である。

目録法は、この目録を作るための方法とルールのことである(筆者の整理)。日本では『日本目録規則2018年版』がそのルールにあたる。

典拠: 岩手大学図書館「図書目録」(2025年)(『日本目録規則2018年版』用語解説にもとづく目録の定義) / カレントアウェアネス CA1951(NCR2018の位置づけ)
注:「目録法」という語そのものを定義した文は確認できていない。上の説明は、目録の定義とNCR2018から筆者がまとめた。

SQL

SQL(Structured Query Language)とは、リレーショナルデータベースを操作するための標準的な言語である。

国際規格 ISO/IEC 9075 で決められており、データの入れ物(構造)を定義することと、そのデータを操作することを扱う。

典拠: ANSI Blog「The SQL Standard」(標準的な言語であること) / GlobalSpec「ISO/IEC 9075-2」(規格が扱う範囲)
